# Paradise Nursery

A responsive plant-shop application built with React, Vite, Redux Toolkit, and React Router.

## Features
- Landing page with a Get Started button
- About Us page
- Product listing grouped by plant category
- Add-to-cart and quantity management
- Shopping cart with subtotal and remove controls
- Responsive layout

## Run locally
1. Install Node.js (18 or newer).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Main files
- `src/App.jsx` — routes and app layout
- `src/App.css` — global styles and landing background
- `src/AboutUs.jsx` — company information
- `src/CartSlice.jsx` — Redux cart reducers
- `src/ProductList.jsx` — product listing
- `src/CartItem.jsx` — shopping cart page
